# 素笺 (su-jian)

一款自己给自己做的 Markdown 编辑器。

## 为什么会有这个项目

市面上的 Markdown 软件试了一圈，没有一个能顺手用：

- 有的功能堆得很满，但真正每天要用的那几样反而藏得很深；
- 有的把编辑器做得像笔记平台，强制登录、强制同步、强制塞一堆用不上的模板和插件；
- 有的写起来卡，长文档滚一下就掉帧；
- 有的导出、图片管理、暗色模式这些基础体验做得很将就。

用着别扭，改又改不动，于是干脆自己做一个——**通过 AI 辅助编程（vibe coding）从零搭起来，完全按自己的使用习惯来**。

## 这个项目要干什么

**做一个安静、轻量、只做 Markdown 的本地编辑器。**

- 打开本地 md 文件就能写，写完保存回本地，文件始终在自己手里；
- 专注写作本身：一个干净编辑区、必要的侧边文件树、Typora 式单页即时渲染（没有分屏、没有模式切换）；
- 图片能力本期不做，只保留原始图片语法文本，不加载图片；
- 暗色模式、导出这些基础体验做扎实，不花哨；
- 同一个软件在 Windows、macOS、Linux 上都能跑，换电脑不用换习惯。

## 不做什么

明确砍掉的东西，避免越做越复杂：

- ❌ 不做云同步、不做账号登录
- ❌ 不做团队协作、不做在线分享链接
- ❌ 不做笔记库/知识库那套体系，只认文件夹里的 `.md` 文件
- ❌ 不塞插件市场、不塞模板中心

## 定位

自用项目，一个人维护，慢慢迭代。功能少一点没关系，**每一处都必须是自己在用的那一种顺手**。

## 状态

v0.1（P0 核心闭环）已完成第一版实现：打开 / 保存 / 另存为、单页即时渲染、语法渲染、
文件夹文件树、新建文件与子文件夹、未保存保护、编码兼容、拖拽与命令行打开。

外观提供亮色 / 暗色 / 跟随系统三种模式，右上角「外观」菜单切换，偏好只存在本机。
亮色为浅灰页面 + 白色编辑卡片 + 青绿强调，暗色为深灰蓝底 + 紫色强调 + VS Code 风格代码高亮，
配色参考 `doc/` 下的设计图。文件树中悬停文件夹节点点「+」可新建子文件夹。

技术栈：Tauri 2 + Vite + TypeScript（前端无框架），Rust 侧只保留最小文件读写命令。

### 本地验证

```bash
npm install
npm run verify   # 核心逻辑回归（分块往返、渲染、编码）
npm run build    # 类型检查 + 前端构建
```

### 运行桌面版

桌面版需要 Rust 1.90+（本项目环境未安装，需先安装 rustup）：

```bash
npm run tauri dev
```

需求细节见 `doc/su-jian-prd.md`。
